# Plan: Bug-Fix `restoreTurnContext()` in `doCall()`

## 1. Context
`restoreTurnContext()` wird aktuell nur nach `compressContext()` aufgerufen. Auf Turn 1 und allen Turns ohne Compact fehlt der Turn-Context (AGENTS.md, Project-Info, Standing Orders).

## 2. Design decisions
- `restoreTurnContext()` in `AbstractAgent.doCall()` vor `toolService.executeLoop()` aufrufen. ✅
- Der bestehende `contains`-Check in `restoreTurnContext()` verhindert Duplikate auf Turn 2+. ✅

## 3. Affected files
- `/llmpeon-parent/org.sterl.llmpeon.core/src/main/java/org/sterl/llmpeon/agent/AbstractAgent.java` — `doCall()` (Zeile ~227). ✅
- `/llmpeon-parent/org.sterl.llmpeon.core/src/test/java/org/sterl/llmpeon/agent/AbstractAgentTest.java` — Test anpassen/neuen hinzufügen. ✅

## 4. BDD acceptance
- GIVEN Turn 1 (Memory leer, kein Compact passiert)
- WHEN `call("ping", monitor)`

- GIVEN Turn 2 (Context bereits vorhanden)
- WHEN `call("pong", monitor)`
- THEN Memory enthält Context genau einmal (kein Duplikat) ✅
