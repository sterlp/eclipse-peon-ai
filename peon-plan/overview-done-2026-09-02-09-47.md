## 2. Design decisions

- **D1 — Core: `Example` um `description` erweitern.**
  ```java
  public record Example(String name, String json, String description) {}

  public static final Example GPT       = new Example("GPT", "{\"prompt_cache_key\": \"llmpeon\"}",
          "Sets prompt_cache_key for Azure GPT-5* prompt caching");
  public static final Example CLAUDE    = new Example("Claude", "{\"cache_control\": {\"type\": \"ephemeral\"}}",
          "Sets cache_control for Claude prompt caching (gateway form)");
  public static final Example LLAMA_CPP = new Example("llama.cpp", "{\"chat_template_kwargs\": {\"enable_thinking\": false}}",
          "Disables thinking/reasoning in llama.cpp models");

  public static List<Example> all() { return List.of(GPT, CLAUDE, LLAMA_CPP); }
  ```
  - Strings exakt wie PO-Vorgabe. Class-Javadoc: Bulle für das llama.cpp-Beispiel ergänzen
    (dort dokumentiert schon heute je Beispiel die Semantik).
  - `chat_template_kwargs` ist kein reserved key (`model`/`messages`/`tools`) → bestehender
    Parameterized-Test passiert ohne Änderung.
- **D2 — Plugin-UI: `buildJsonExamples()` kompakt.**
  - Eine Vollbreite-Zeile (Composite, `horizontalSpan=2`) mit `GridLayout(n+1, false)`:
    `[Label "Examples:"] [Button "GPT"] [Button "Claude"] [Button "llama.cpp"]`
    (n = `ExtraBodyExamples.all().size()`).
  - `Button(PUSH)`, Text = `example.name()`, `button.setToolTipText(example.description())`.
  - Klick → bestehendes `pasteExample(example)` **unverändert** (Feld-Replace + Status-Label
    "<name> example inserted.").
  - Status-Label (`examplesLabel`) bleibt **darunter** (eigene Zeile, span 2) wie heute.
  - `buildJson(...)`/`pasteExample(...)`/Provider-Gate (`supportsExtraBody()`) unverändert.
  - Javadoc von `buildJsonExamples()` anpassen (heute: "one row per example (label + paste button)").
- **D3 — Core-Test: eine Zeile ergänzen** — `assertThat(example.description()).isNotBlank()` im
  bestehenden Parameterized-Test (Tooltip-Content ist User-facing; LLAMA_CPP wird automatisch mitgedeckt).
- **D4 — Homepage:** `advanced-configuration.md` → "Two paste-ready examples" → "Three …";
  Examples-Tabelle um Zeile **llama.cpp** (`{"chat_template_kwargs": {"enable_thinking": false}}` —
  Disables thinking/reasoning in llama.cpp models) ergänzen; "Click **Paste** to insert an example"
  → Buttons sind je Beispiel benannt (Klick auf den Beispiel-Button).
