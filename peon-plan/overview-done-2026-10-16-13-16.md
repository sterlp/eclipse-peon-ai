```java
/** Strips a single trailing `*` wildcard suffix; unchanged when absent. */
private static String stripWildcard(String token) {
    return token.endsWith("*") ? token.substring(0, token.length() - 1) : token;
}
```
- `enables` :47-48 (Allow-Pfad) wird zu:
  `anyMatch(t -> isAllowToken(t) && (t.equals("*") || toolName.startsWith(stripWildcard(t))))`
- `matchesNegation` :56-60 nutzt denselben Helper:
  `var prefix = stripWildcard(token.substring(1)); return !prefix.isEmpty() && toolName.startsWith(prefix);`

- **Semantik-Kanten (deterministisch, im Test gepinnt):** `*` allein bleibt der All-Token

  identisches Verhalten; gestrippte Allow-Tokens waren vorher wirkungslos (SOLL :170-171).
