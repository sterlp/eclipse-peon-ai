# E2E: Plan ohne Plan-Tools (der Plan ist die Chat-Antwort)

Regeln: siehe [README.md](README.md) — Black Box, nur Fehler melden.

1. Lies wenigstens eine Datei.
2. Erstelle den Plan für eine Hello-World-Java-Datei **direkt als Chat-Antwort** — keine Plan-Tools.
3. Führe den Plan aus.
4. Wenn alles klappt: die Datei wieder löschen und „OK" melden.
5. Bei Problemen: `plan-problem-e2e.md` anlegen (Form siehe [README.md](README.md)).
