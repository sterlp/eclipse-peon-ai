# E2E: Plan über die Plan-Tools (bauen + archivieren)

Regeln: siehe [README.md](README.md) — Black Box, nur Fehler melden.

1. Lies wenigstens eine Datei des Projekts.
2. Erstelle einen Plan, der eine Hello-World-Java-Datei erzeugt und ausführt — über die Plan-Tools.
3. Baue den Plan.
4. Prüfe: die Datei existiert und die Ausgabe ist korrekt.
5. Schließe den Plan ab (`planImplemented`): er wird archiviert, `peon-plan/overview.md` ist danach
   weg.
6. Räume auf (die Hello-World-Datei löschen), dann melde „OK".
7. Bei Problemen: `plan-problem-e2e.md` anlegen (Form siehe [README.md](README.md)) — mit Schritt,
   Aufruf, erwartet, tatsächlich.
