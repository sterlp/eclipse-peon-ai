# E2E: Jon plant → Da Thinka schreibt den Plan → Da Mek baut

Regeln: siehe [README.md](README.md) — Black Box, nur Fehler melden.

1. Lies wenigstens eine Datei.
2. Erstelle ein Test-Doc (z. B. `docs/e2e-hello.md`).
3. Lass einen Plan erstellen, der ein Hello-World in Java baut und ausführt.
4. Lass den Plan bauen.
5. Wenn alles klappt: das Test-Doc löschen und alles wieder aufräumen lassen.
6. Bei Problemen: lass eine klare Problemanalyse erstellen. Du testest dich selbst — der Code hier
   bist du, Fehler dürfen direkt soweit möglich geprüft werden (White Box erst nach dem Befund,
   Datei + Zeile im Befund nennen).
